System tray

Mandor keeps running in the tray when the window closes, so agents keep working. The tray menu is a short way back to anything waiting for you. Click the icons below to open each menu.

Tray menu

Native menu, drawn by the OS. Up to 5 waiting runs are listed, oldest wait first; a 6th and beyond collapse into "Show all on the board".

Tray icon

Monochrome mark so it follows the OS theme (macOS template image). The attention variant adds a dot when at least one run is waiting for you, failed, or needs attention.

Behaviour

  • Closing the window hides it; agents and syncing continue. Turn this off in Settings › General › "Keep running in the tray when closed".
  • Clicking the icon (left click on Windows and Linux) opens the menu; "Open Mandor" restores the window where it was.
  • A waiting item opens that task's workspace and brings the window to the front.
  • Quit Mandor asks for confirmation only when runs are active: "3 agents are running. They keep running in the daemon; Mandor reconnects next time you open it."
  • Tooltip on hover: "Mandor · 2 waiting for you" or "Mandor · all quiet".
