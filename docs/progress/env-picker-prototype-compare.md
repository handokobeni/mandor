Temuan selama uji dan perbaikannya (branch `feat/prototype-compare`):

- App multi-tenant per domain: App URL dan URL prototype menerima `*.localhost`. Aturan host prototype mengikuti jangkauan cookie (host sama, subdomain host app, atau induk yang bukan sufiks publik; `localhost` diperlakukan sebagai sufiks publik). Di WSL, Chrome di Windows tidak menjangkau `127.0.0.1` milik WSL, jadi prototype memakai nama `*.localhost`.
- Ekstensi Claude in Chrome baru menuntut `tabs_context_mcp` dengan `createIfEmpty` sebelum `tabs_create_mcp`; reviewer tidak lagi mencoba resize jendela Chrome dev.
- Link app di kontrol Run app dan link perbandingan memakai repo yang diuji browser (`AppMemberView.browser_tests`); dialog Run app menyebut prototype yang ikut jalan; dialog gerbang dan panel Push blocked menampilkan alasan tampilan.
- Baris yang hanya beda tampilan bisa dipilih untuk Send to agent; pesan ke agent menyebut tampilan berbeda.
- Run terikat Base asalnya (`runs.scope`, migrasi 0011) dan run parkir pulih bila klaim masih milik daemon ini; ditemukan saat berganti ke Base sungguhan yang berbagi `record_id` dengan Base copy.
- Agent diarahkan ke bentuk perintah yang tidak ditolak Claude Code (`cd` terpisah dari `git`, tanpa `git -C`/`--dir`, tanpa pipe, path tanpa `( ) [ ]`), `gofmt` di allowlist. Perbaikan tuntas (hook Mandor memberi izin eksplisit) direncanakan terpisah.

Belum diuji: perubahan berkas prototype memunculkan konfirmasi revisi baru, Push anyway pada baris Differs (butuh push sungguhan), dan uji VM (Playwright 1440x900, screenshot).
