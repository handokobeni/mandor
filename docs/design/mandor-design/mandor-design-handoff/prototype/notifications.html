Notifications

One event list feeds both the desktop notifications and the in-app notification center (bell in the title bar). Copy below is final; the operating system draws the desktop notification, Mandor only supplies the icon, title, and body.

Desktop notifications

Click opens Mandor on the task's workspace. No action buttons: notification actions behave differently on Windows, macOS, and Linux, so every action stays in the app.

When Mandor notifies

  • One notification per event, never per tool call or per streamed message.
  • Not when you are already looking. If the Mandor window is focused on that task's workspace, the event only goes to the notification center.
  • Grouped bursts. Three or more "waiting for you" events within 10 seconds become one notification: "3 agents are waiting for you", which opens the board.
  • Waiting Fix respects the quiet period. "Reviewer requested fixes" fires once when the task enters Waiting Fix, not for every comment.
  • Each kind can be switched off in Settings › General. Defaults: everything on except PR created.
  • Tray close notice. The first time the window closes while agents run: "Mandor is still running in the tray. Agents keep working." Shown once.

Notification center

Bell in the title bar with an unread count. Newest first, unread rows tinted and dotted, click opens the task and marks it read. Try it live from the title bar of any screen.
