RPC `design_sources.revision` dan `design_sources.confirm` untuk konfirmasi tanpa Run app (dialog "Prototype code" di daftar sumber desain, laptop dan VM). UI: "Open prototype" di kontrol Run app, nama prototype di dialog konfirmasi. Test: 3 adapter git, 1 adapter desain, 5 usecase app_run, 1 usecase VM (AE15), 1 integrasi daemon, 3 Vitest. Perbaikan lanjutan dari review keamanan otomatis: diff memakai `--no-ext-diff --no-textconv`; revisi repo git dihitung dari `ls-files` dan isi berkas langsung (tanpa `status`/`diff` worktree yang menjalankan clean filter); daftar perubahan belum di-commit dihitung dengan `hash-object --no-filters` terhadap `ls-tree HEAD`. |
